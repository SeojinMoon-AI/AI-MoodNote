# [MoodNote] 작품 제안서

> **폰을 꺼내기 어려운 순간에도 버튼 한 번으로 남기는 감정 기록 기기 + 분석 앱**
> - **작성일**: 2026.10.12
> - **팀 구성**: 팀장 서유정, 팀원 이진우(SW), 문서진(HW)

---

## 1. 한 줄 요약
**MoodNote**는 폰을 꺼내기 어려운 순간에도 버튼 한 번으로 감정을 음성으로 남기고, 앱이 그 기록을 컨디션과 함께 정리해 패턴을 보여주는 휴대용 감정 기록 기기다.

| 구분 | 주요 내용 |
| :--- | :--- |
| **기기 (HW)** | 휴대용 단일 버튼 음성 기록기 (ESP32-S3, 마이크, 배터리) |
| **앱 (SW)** | 감정 단어 선택, 하루 컨디션, 그래프, 위로와 질문형 AI 피드백 |
| **포지셔닝** | 상담·진단이 아닌 감정 분석 도구 (12/21까지 기기+앱 완성 목표) |

---

## 2. 문제와 기회
* **배경**: 감정은 삶의 핵심 변수이며, 감정을 기록하고 이름을 붙이는 것만으로도 스트레스 완화와 감정 조절에 도움이 된다는 연구가 다수 존재함.
* **문제 (Problem)**: 감정은 지나가는 순간이 가장 정확하지만, 스마트폰 잠금 해제와 앱 실행의 번거로움 때문에 타이밍을 놓침[cite: 7]. (팀장 개인 경험: 요가 수업 중 폰이 사물함에 있어 미기록, 폰 시작 시간 추정 5~10초)
* **설계 원칙**: 치료가 아닌 일상 기록과 되돌아보기를 돕는 웰니스 도구로 설계.
* **시장 현황**: AI 녹음기(Plaud 등)와 AI 일기 앱(Rosebud, Wysa 등)이 있으나, 감정 기록에 특화된 전용 음성 기기는 부재.

## 3. 제품과 차별점

**목표 고객**: 수업·회의 중 폰을 쓰기 어려운 대학생과 회사원
1. **순간 캡처 (기기가 필요한 이유)**: 버튼 한 번으로 녹음 시작, 알림 없는 격리된 환경에서 즉각 기록.
2. **분석 (앱)**: 100단어 무드미터(에너지×쾌적도)로 감정 확정, 수면/컨디션 결합 그래프, 질문형 피드백.

## 4. 사업성 분석

- **수익 모델**: 기기 1회 판매 + 분석/AI 피드백 구독
- **원가 및 가격 기준**:
  - 기기 원가(BOM): 45,000원
  - 기기 판매가: 99,000원 (대당 매출총이익 54,000원)
  - 구독료: 월 3,900원 (연 46,800원)
  - API 비용: 월 630원/명 (하루 3건, 30초 기준)
- **핵심 시사점**: 구독 매출만으로는 API 비용 보전이 어려우므로 기기 마진을 통해 충당하는 구조로 설계.

## 5. 신뢰 및 규제 대응
* **표현**: "우울증 예방" 등의 효능 문구를 배제하고 비의료 웰니스 도구로 포지셔닝.
* **동의 & 프라이버시**: 수집/전송 6개 항목 분리 동의, 음성 원본은 변환 후 서버 즉시 삭제 원칙.
* **위기 대응**: 위험 신호 3단계 분류 및 전문 위기상담 안내.

## 6. 개발 단계 및 일정 계획

* **반드시 (필수)**: 텍스트·음성 입력, 저장, 100단어 선택, 컨디션 기록, 동의/삭제, 기기 녹음 업로드
* **그다음**: 무드 추이 그래프
* **가능하면**: AI 피드백, 하드웨어 부가 기능
* **일정**: 12/21 학기 종료 전 완성 목표 (11/16까지 PCB 미입고 시 개발보드 시연 컨틴전시 가동)

### 교수님 검토 요청 사항
1. 제품 방향(기기 + 앱 결합, 앱 우선 개발) 승인
2. 학기 말 통과 기준에 맞춘 개발 범위 조언
3. 상품성 보강을 위해 필요한 검증 항목 피드백
