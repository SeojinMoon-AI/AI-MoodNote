# MoodNote 웹 UI/UX 디자인 상세 명세

> **톤앤매너**: 따뜻한 아날로그 감성(아이보리 노트 종이 질감, 손글씨) + 인터랙티브 구슬 시각화

---

## 1. 메인 뷰 (First View: 진입 시)

* **배경 스타일**:
  * 연한 미색 (아이보리 / 노트 종이 색감)
  * 옅은 가로 줄무늬 노트 라인 (CSS 패턴 적용)
* **중앙 입력창**:
  * 연필로 밑줄을 그어놓은 듯한 미니멀한 검색바/입력 라인
  * **텍스트 입력**: 내용 입력 후 엔터 시 즉시 일기 저장 및 감정 분석 파이프라인 호출
  * **마이크 아이콘**: 클릭 시 브라우저 오디오 녹음 활성화 (물리 기기가 없을 때도 웹에서 동일하게 음성 일기 작성 지원)
* **서브 링크 (상/하단 미니 버튼)**:
  * 구글 기념일 링크 스타일의 손글씨 텍스트 버튼
  * `[ ✏️ 요즘 나의 마음 날씨 보기 ]`, `[ ☕ 오늘 컨디션 체크 ]`

---

## 2. 잔디밭 뷰 (무드미터 4분면 캘린더)

기존 깃허브의 단순 녹색 잔디 대신, **무드미터(Mood Meter) 4분면 100단어 좌표 색상**이 날짜별로 시각화됩니다:

| 분면 | 색상 | 에너지 / 쾌적도 | 대표 감정 |
| :---: | :---: | :---: | :--- |
| **1분면** | 🔴 **빨강** | 고에너지 - 저유쾌 | 분노, 불안, 짜증 |
| **2분면** | 🟡 **노랑** | 고에너지 - 고유쾌 | 성취, 기쁨, 열정 |
| **3분면** | 🔵 **파랑** | 저에너지 - 저유쾌 | 우울, 무기력, 피로 |
| **4분면** | 🟢 **초록** | 저에너지 - 고유쾌 | 평온, 차분, 안정 |

* **시각적 특징**:
  * 사용자가 글을 읽지 않아도 최근 감정들의 총합(전체 색감 톤)을 직관적으로 체감
  * 입력창 바닥에 반투명(Opacity 20~30%) 상태로 은은하게 깔려 수채화 배경지 느낌 연출
* **등록 인터랙션 (구슬 드롭)**:
  * 웹 또는 전용 기기에서 새 일기가 저장되는 순간, 상단 미니 레일에서 해당 감정 색상의 구슬 하나가 "통~" 하고 떨어져 바닥에 합류하는 피드백 애니메이션 제공

---

## 3. 원통형 롤링 캘린더 (회전초밥 / 캐러셀 뷰)

상/하단이 부드러운 곡선으로 마감된 필름 롤·원통형 캘린더 인터랙션:

* **동작 방식**:
  * 한 화면에 한 달(예: Aug) 분량의 구슬들이 요일/주차별(세로 7줄 또는 가로 칸)로 배치
  * **미기록 일자**: 연한 회색 빈 구슬 형태 유지
  * **기록된 일자**: 해당 감정 색상(빨/노/파/초)으로 채워짐
* **화면 전환**:
  * 마우스 휠 스크롤 또는 좌우 방향키/버튼 조작 시 원통이 돌아가듯 부드러운 곡면 애니메이션과 함께 월별(8월 → 9월)로 슬라이드 전환
