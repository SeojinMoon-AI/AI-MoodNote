# MoodNote 팀 회의록 및 기획/개발 현황 (2026-10-11)

## 1. 프로젝트 정체성 및 소구점 (Why Dedicated Hardware?)
- **핵심 포지셔닝**: 일상 기록 및 자기이해를 돕는 **정서적 웰니스(Wellness) 도구** (의료기기 분류 회피를 위해 '우울증 예방/치료' 등의 표현 지양)
- **스마트폰 대비 물리 기기만의 차별점**:
  1. **Zero-Friction (0초 캡처)**: 잠금 해제와 앱 탐색 마찰 없이 단일 버튼 조작으로 즉각 기록
  2. **Distraction-Free (알림 격리)**: SNS, 메신저 등 도파민 자극 없이 기록과 위안에만 몰입
  3. **Emotional Hardware**: 다마고치/피젯 토이와 같이 촉각적 피드백과 정서적 애착 형성
- **경쟁 제품 대비 차별화 (vs Plaud NotePin)**:
  - Plaud: 회의·강의·업무 생산성 중심
  - MoodNote: 5~10초의 짧은 감정 맥락, 하루 기분 추이, 자기 이해 중심

---

## 2. 하드웨어(HW) 및 기구 전략 결정사항
- **폼팩터 및 포지셔닝**:
  - 1차 버전: 가방 참(Charm), 키링, 데스크테리어 오브제 형태
  - 초소형 워치 형태($40\times 40\text{mm}$)는 4층 기판 및 부품 고집적화가 필요하므로 v2(차기 양산) 로드맵으로 기술
- **HW 플랫폼 전환 결정**:
  - 기존: 60x60mm 2-Layer Custom PCB (회로 및 DRC 검증 완료)
  - **변경: Waveshare ESP32-S3 1.54인치 Touch e-Paper 모듈 채택**
  - **선정 이유**:
    - 크기 대폭 축소 ($53 \times 39.8\text{mm}$)로 휴대성 극대화
    - E-Paper 디스플레이 기본 탑재로 '종이 질감 감성' 및 초저전력(1회 충전 장기 구동) 달성
    - 오디오 코덱(ES8311), 온보드 마이크/스피커, MicroSD, RTC(PCF85063), 리튬 배터리 충전 회로 일체형 내장
    - 12월 학기 마감 일정 내 안정적인 펌웨어 개발 및 기구(SLA) 모델링 집중 가능

---

## 3. 핵심 쟁점 및 합의 방향
1. **위치(GPS) 방식**:
   - 하드웨어 GPS 칩셋 탑재 배제 (배터리 소모 및 실내 음영 이슈)
   - 녹음 시 기기에서 주변 Wi-Fi AP BSSID를 스캔해 타임스탬프와 함께 기록하거나, 동기화 시 수동/브라우저 위치 보정
2. **프라이버시 & 데이터 보관**:
   - SD 원본 음성은 서버 동기화 완료 후 자동 삭제(또는 선택적 폐기)
   - 외부 AI/STT API 사용 시 사용자 동의 기반의 안전한 암호화 전송 명시
3. **위기 상담 번호 최신화**:
   - 안전 안내 문구 내 통합 위기상담전화: **`109`** 적용 (2024년 통합 기준 반영)

## 4. 전체 WBS 의존 순서 요약
- **A. 제안서·결정**: 소구점 md v2, 제안서 목차 및 본문 작성 (유정)
- **B. 무드 단어 데이터**: 100칸 격자 데이터 검증 및 CSV 생성 (유정)
- **C/D. DB 및 스키마**: 학교 MySQL 8.0 테이블 생성, 제약조건 검증, mood_words 적재 (진우·유정)
- **E/F. 개발 환경 & API**: GitHub 세팅, 헬스체크/인증/일기/단어 API 구현 (진우)
- **G/H. 음성 입력 & 화면**: WAV 업로드/전사 파이프라인, PWA 웹 UI 와이어프레임 및 화면 구현
- **L/M/N. 하드웨어/기구 (서진)**:
  - Waveshare 모듈 기반 실측 및 맞춤형 SLA 하우징 모델링 (키링 홀, 버튼/마이크 홀)
  - ESP-IDF/Arduino 기반 ES8311 마이크 녹음 → SD 저장 → Wi-Fi 업로드 펌웨어 개발
- **P/Q. 통합 & 마무리**: 기기-서버 통합 테스트, 발표 시연 시나리오 및 졸작 보고서 작성
